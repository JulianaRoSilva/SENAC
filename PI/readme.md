# 🐾 Projeto Integrador (PI)

# PetLife

## Sobre o Projeto

O **PetLife** é um aplicativo que sua principal função será possível criar um QRcode e colocar no PIN da coleira do seu PET para que ele seja encontrado com facilidade por outra pessoa caso ele se perca. A ideia é acionar diretamente o tutor com a localização de onde o cão foi escaneado por outro telefone, se ele permitir. 

A ideia é adicionar outras funções no aplicativo como Fóruns interativos, controle do dia a dia do seu pet, cadastro de mais de um pet, dicar para certos nichos, etc.
