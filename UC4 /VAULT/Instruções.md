# Trabalho Vault

## Moradores

### Classe base: Morador

- Nome, idade, sala

### Classes filhas que herdam de Morador:

- Médico
- Engenheiro
- Soldado
- Cientista

- É necessário que exista um método na classe Morador com polimorfismo nas classes filhas

## Salas

### Classe base: Sala

- Nome, quantidade máxima de moradores e moradores ARRAY
- Adicionar os métodos principal de controle de moradores como Adicionar, remover, alterar
- Adicionar um método de TAREFA, e deixar esse método para aplicar polimorfismo nas salas filhas (realizarTarefa)

### Classes filhas de Sala:

- Reator
- Purificador
- Platação
- enfermaria
- oficina
- dormitório

- Herdam de sala
- Reescrever metodos polimorfo principal da classe Sala

## Necessário fazer:

- Cadastros nas salas
- listar
- alocar morador
- gerenciar (Remover ou alterar moradores das salas)
